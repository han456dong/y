授权，
应该看得见。

辰光 Agent 的 RBAC 授权原型。三种身份、八个页面， 菜单、路由与按钮随权限收敛；被隐藏的操作，可以用「权限透视」看见。

怎么看这套原型
右上角切换管理员 / 运营 / 只读，页面会重新加载。 观察侧边栏、页面按钮与 403 状态如何随身份变化。 顶部「权限透视」会把被隐藏的操作以斜纹显示出来。

三种身份，同一套界面

数量来自内置角色权限矩阵
模块 管理员 运营 只读

页面目录

静态页面位于 docs/ui/rbac
01 登录 选择演示身份，验证码登录；进入后权限开始生效。 打开 02 工作台 我的授权范围、未授予操作与授权变更记录。 打开 03 Agent 管理 按钮级收敛：管理员能删，运营不能删，只读看不到写操作。 打开 04 用户管理 角色分配、账号启停、自我保护与最后超管保护。 打开 05 角色管理 权限账簿：模块 × 操作矩阵，支持整组勾选与三态。 打开 06 权限管理 模块筛选、内置保护、权限码格式校验与创建。 打开 07 403 路由守卫的落地页；不暴露所需权限码。 打开 08 权限加载失败 默认拒绝状态：没有菜单，没有放行，只有重试。 打开
